# MEW v0.7 — "calm connections" · release plan

v0.6 made gbrain the operative spine. v0.7's headline is **making the connected calendar
calm**: the Google leg must never steal attention (no surprise browser tabs, no silent
lies about sync state), all-day events become honest citizens, and the evening stops
being invisible to placement. First public-repo release line.

Working branch: `v0.7-rc` (cut from `main` @ v0.6.0 + the open-sourcing sweep).
Merge feature PRs into `v0.7-rc`; promotion PR `v0.7-rc → main` runs the heavy gates;
tag `v0.7.0` cuts installers. Standing laws unchanged: chat-first, positive-only voice,
tools are the only week-mutation path, keys never leave the device, graceful
keyless/brainless degradation. Merge bar unchanged: plain Approve, zero 🟡, gate proof
in the PR body.

---

## Tier 0 — live-bug fixes (jump the queue)

- **#25 · Google re-auth never auto-opens the browser** — the outbound leg of the
  focus-steal: `authorize(false)` on desktop throws a typed `ReauthRequiredError`
  instead of reaching `oauthLoopback`; sync pauses honestly (`needsReconnect`), one
  kind chat line per pause episode, and **reconnect is a deliberate click in
  Settings**. *(This RC — in progress.)*
- **#27 · All-day events get a real lane** — stop dropping date-only events and stop
  minting 0:00–23:59 blocks; `Block.allDay` as a third axis, a week all-day lane,
  dial badges, and the math fallout (day-load, live-now, rescue) corrected.
- **#22 · The evening exists** — `DAY_END=18:30` caps every placement path and makes
  MEW deny free evenings that are plainly there. Placement honors the owner's real
  day bounds.

## Tier 1 — auth that opens the browser exactly once

- **#26 · Auth-code + PKCE + refresh token on desktop** — retire the hourly implicit
  grant entirely: the browser opens on the deliberate connect click and then never
  again. Phase-0 verifies the loopback + token exchange against Google's current
  desktop-app policy before the migration lands.

## Tier 2 — reach & depth (carry-overs, promoted as they're picked up)

- **#6 · Self-updater signing infrastructure** — signed updater artifacts on tag;
  existing installs update in place.
- **#16 · Calendar command surface (standing track)** — split / merge / batch next;
  grows every RC.
- **#9 / #8 · Close-out audits** — windowed chat log and gbrain-connection honesty
  both shipped in v0.6; verify against the live checklist and close.
